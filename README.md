# تطبيق أبو حمزة للأندرويد

هذا مشروع Android WebView يفتح نسخة البرنامج المنشورة:
https://visionary-empanada-3cbba9.netlify.app/

## بناء ملف APK من الموبايل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم AbuHamza.
2. افتح تبويب Actions في المستودع.
3. اختر Build Abu Hamza APK ثم Run workflow.
4. بعد انتهاء البناء افتح النتيجة من Artifacts ونزّل AbuHamza-APK.zip.
5. فك الضغط وثبّت app-debug.apk على هاتف Android.

ملاحظات:
- هذا التطبيق غلاف أندرويد للنسخة السحابية الحالية، وليس إعادة كتابة مستقلة للبرنامج.
- أول تشغيل قد يطلب تسجيل الدخول داخل التطبيق. هذا متوقع لأن بيانات تسجيل الدخول المحفوظة في Chrome لا تنتقل تلقائياً إلى التطبيق.
- لا يحذف أو يعدّل بيانات Firebase. لا تشارك بيانات الدخول أو مفاتيح المشروع علناً.
